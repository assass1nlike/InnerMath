# InnerMath 实验规范

每项研究至少记录以下内容：

1. **对象**：模型、训练任务、层或组件、提取的表示、样本与坐标约定。
2. **数学假设**：结构、运算或作用的定义，需要成立的关系，以及允许的近似方式。
3. **拟合与评估**：分开拟合数据和验证数据；说明模型训练划分与结构探针划分是否重合。
4. **对照**：已知结构的正对照、随机或打乱对照、训练前后比较；避免让拟合过程直接强制产生待验证关系。
5. **指标**：明确范数、归一化、维度、秩、正则化、数值精度及预期失败情形。
6. **复现材料**：随机种子、依赖版本、模型参数、配置、原始指标及运行命令。大文件放在忽略的输出目录。
7. **结论边界**：区分数据可视化、统计证据、因果证据和数学证明。负结果同样保存。

结构证据不应只依赖一张降维图或一次成功的拟合。对称的输入任务不保证隐藏表示具有相同对称性；网络初始化或数据编码也可能直接带来结构。对模型内部结构的解释需要排除这些替代原因。

未来加入其他模型和表示时，应优先复用数学检验，而不是将所有表示硬转成图片 embedding。当前 `probe_cyclic` 接受 `(轨道数, 群阶数, 特征维数)` 的 NumPy 数组，可用于其他来源的激活。
