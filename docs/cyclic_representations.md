# 循环群在隐藏表示中的探针

## 数学问题

循环群 `C_n = Z/nZ` 由一个生成元构成。实线性表示由可逆矩阵 `T` 确定，满足 `T^n = I`。如果隐藏表示对输入平移等变，采用行向量约定，应有

```text
h(a + k mod n, b) = h(a, b) T^k
```

网络为 `onehot(a) ⊕ onehot(b) → tanh hidden → n-class logits`，监督标签是 `(a+b) mod n`。所有参数由 NumPy 实现的全批量 Adam 训练。模型结构没有显式群等变性约束，也没有使用正弦/余弦编码。

## 两种不同的留出划分

**任务划分**：默认随机选择 80% 的 `(a,b)` 输入对训练分类器，20% 评估任务准确率。任务留出准确率低时，不能声称模型学到了泛化的模加法算法。

**探针划分**：固定 `b`、遍历全部 `a` 构成一条完整轨道。随机选约 70% 的 `b` 轨道拟合 `T`，其余轨道只用于验证。它检验算子能否跨轨道复用，不等于在模型从未见过的数据上验证；部分探针验证输入可能用于过网络训练。这两种划分均写入报告。

令训练轨道展开得到 `X`，向前平移一个群元素得到 `Y`。拟合

```text
T = (Xᵀ X + λ I)^(-1) Xᵀ Y
λ = ridge · ||Xᵀ X||₂
```

实现使用线性求解，不显式求逆。拟合不强制正交或 `T^n=I`。默认 `ridge=1e-6`，也可通过 `--ridge` 改变。所有指标使用未经中心化的隐藏状态，以保留可能存在的平凡子表示。

## 指标

- **等变误差**：`||H T - shift(H)||F / ||shift(H)||F`，训练和验证分别报告。
- **幂误差**：对 `k=1,...,n-1` 检查 `T^k` 与直接平移 `k`；`test_mean_power_error` 是这些相对误差的均值。
- **状态上的循环误差**：`||H T^n - H||F / ||H||F`。
- **环境空间循环误差**：`||T^n-I||F / ||I||F`。当训练数据不满秩时，未观测方向上的作用无法由数据确定，因此该指标可能大，而状态上的误差小。
- **谱距离**：每个特征值到最近 n 次单位根的距离，再取均值。低谱距离本身不保证矩阵满足群关系（例如非平凡 Jordan 块），所以必须结合幂与循环误差。
- **特征标能量**：沿群元素轴进行 DFT，报告各 `χ_k(g)=exp(2πikg/n)` 的能量占比；实表示中共轭频率成对出现。任意按循环顺序索引的数据都有 DFT，因此非零频谱不是发现群表示的充分条件。

误差和能量依赖所选特征度量；一般非正交换基可改变数值。正交换基下的等变性由测试覆盖。高阶幂可能放大数值误差，当前报告不自动把某个阈值解释为结构存在。

## 对照

- **untrained**：相同网络训练前的隐藏状态，判断结构是否来自输入编码和初始化。
- **shuffled**：训练后的每条轨道独立打乱 `a` 的顺序，保留点集但破坏共同的平移对应。
- **exact_control**：人为构造频率 1、2 的两个二维旋转表示，施加随机正交换基。它只检验探针能否识别已知结构，不属于模型发现。

如果 trained 的任务准确率高，但群关系不成立，合理结论是“在这些设置下，当前线性探针没有支持该结构”。不应通过只报告有利指标隐藏失败，也不能把线性探针的失败推广为不存在任何非线性结构。

## 复现与扩展

```powershell
innermath --seed 0 --output-dir outputs/cyclic/seed0
innermath --seed 1 --output-dir outputs/cyclic/seed1
innermath --seed 2 --output-dir outputs/cyclic/seed2
```

`artifacts.npz` 保存训练前后参数、输入、标签、隐藏状态、对照和拟合生成元。`report.json` 保存全部划分、训练损失抽样与指标。后续应加入更多种子、超参数扫描、任务泛化更好的模型及输出干预。

数学背景可参阅 Serre, *Linear Representations of Finite Groups* 中有限群表示与特征标的基础章节。本实验只覆盖循环群的线性表示诊断，不实现一般不可约分解。
