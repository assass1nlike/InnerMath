# InnerMath 研究路线

目标是探寻模型内部表示中的数学结构，尤其是非平凡的纯数学结构。各方向按“假设—可执行实验—对照—结论边界”推进，不将高级数学名词作为已经得到的结果。

## 已实现

- 循环群 `C_n`：训练模加法 MLP，拟合隐藏层线性生成元，测试留出轨道上的等变性、群关系和特征标能量；包括未训练、打乱和精确表示对照。
- 图片 embedding：保留 CLIP 等编码器、12 种向量操作、近邻检索、合成图库及批量评测。这是一个探索分支，不代表整个项目的范围。

## 下一步：把群表示实验做扎实

1. 多种随机种子、隐藏层宽度、模数和正则化强度，统计失败比例与误差分布。
2. 比较任务泛化良好和仅记忆训练集的模型；当前小型 MLP 不保证学会模加法的泛化算法。
3. 分离平凡子表示与非平凡成分，在训练子空间内分析；检查换基、坐标尺度和拟合秩的影响。
4. 因果干预：用拟合算子替换隐藏状态，验证输出是否按群作用变化，并与同范数随机干预比较。
5. 扩展到非交换群，如二面体群；分别拟合两个生成元，检查 `r^n=e`、`s^2=e`、`srs=r^-1`。这部分尚未实现。

## 候选方向（尚未实现）

| 数学方向 | 模型中的候选对象 | 可检验问题 |
|---|---|---|
| 表示论与交换子代数 | 隐藏子空间、群作用算子 | 是否存在稳定的不变子空间？交换子代数是否支持分解？ |
| 李群与李代数 | 连续输入变化诱导的局部算子 | 局部生成元的交换子是否满足预期关系？有限变换是否与指数映射一致？ |
| 代数拓扑 | 条件化激活点云 | 持续同调特征是否跨采样、尺度和随机种子稳定？是否超出空模型？ |
| 微分几何 | 隐藏状态流形、Jacobian | 局部度量、切空间和曲率是否反映任务因素？ |
| 算子代数 | 注意力与层间映射 | 组合、交换性和谱结构是否与功能分解对应？ |

每个方向先确定数据、作用或运算，再讨论是否满足数学定义。例如，不能因为向量能相加就称其形成了具有研究意义的群，也不能在没有定义乘法和验证公理时声称发现了环或域。

## 图片分支后续

已有脚本支持合成图库和真实图库评测。可继续比较模型、检索解码和生成式解码，但应将发现转化为关于不变性、等变性或结构关系的假设。运行方式见 [图片基线](image_embedding_baseline.md)。
